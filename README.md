
# e-plantShopping
## Description
e-plantShopping est une application web interactive d'e-commerce permettant aux utilisateurs de parcourir une sélection de plantes d'intérieur, de consulter leurs caractéristiques et prix, et de gérer dynamiquement un panier d'achat.

## Fonctionnalités
- Page d'accueil descriptive avec bouton de démarrage direct
- Catalogue de plantes organisé par catégories avec filtres interactifs
- Panier d'achat avec mise à jour en temps réel des quantités et du montant total
- Badge de notification dynamique sur l'icône du panier

## Technologies utilisées
- React.js
- Redux Toolkit (ou React Context API / State Management)
- CSS3 / Tailwind CSS
